# TOP-G page photo folders

Add real project photos to these folders. Use numeric filenames so the page order is predictable: `1.webp`, `2.webp`, `3.webp` (and optionally `4.webp` onward). The site accepts `.webp`, `.jpg`, `.jpeg`, and `.png`; it uses only the first three after numeric sorting.

Expected paths:

- `services/leather-seat-cover/1.webp` through `3.webp`
- `services/door-sidings/1.webp` through `3.webp`
- `services/ceiling/1.webp` through `3.webp`
- `services/home-service/1.webp` through `3.webp`
- `materials/nylex/1.webp` through `3.webp`
- `materials/montecarlo/1.webp` through `3.webp`
- `materials/copper/1.webp` through `3.webp`

Photo guidelines:

- Prefer landscape 4:3 photos; the card crops to a fixed 4:3 frame with `object-fit: cover`.
- Use clear, well-lit photos of the relevant TOP-G work.
- Keep files optimized for the web. WebP is preferred.
- Do not add logos, captions, or text overlays; the website supplies accessible alt text automatically.
